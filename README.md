# External service

This is a heavily mocked service to support [trip-advisor](https://github.com/Mick-J/trip-advisor) `scalability test with virtual thread` project demo.

Support 2 major functionalities: trip planning and flight search-reservation
- trip-planning endpoints
```shell
# planning services
trip-planning/accommodations/
trip-planning/events/
trip-planning/local-recommendations/
trip-planning/transportation/
trip-planning/weather/
```

-  flight search-reservation endpoints

```shell
# flight services
flight/search/
flight/reserve/
```
